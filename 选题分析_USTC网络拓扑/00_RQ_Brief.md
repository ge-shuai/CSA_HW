## 1. 研究问题

**主问题**：

> 在 USTC 子域超链接网络中，共享导航模板在多大程度上塑造了网络结构？观测到的站点失效在网络上如何分布？网络对“已经发生的失效”和“可能发生的核心故障”分别有多韧？

**拆成四个子问题**：

1. **结构**：剥离模板/弱边后，社区结构、中心性排序如何变化？
2. **失效**：全挂/部分失效在网络上如何分布？是否聚集？与度、类别、URL 规模的关系是什么？
3. **韧性**：随机失效、观测失效、蓄意攻击三种情景下，GCC/全局效率如何变化？谁是“关键但当前健康”的尾部风险？
4. **治理**：如何把结构重要性与健康度组合成可操作的风险矩阵？

## 3. 范围边界

### In scope

- 671 个有属性的 `*.ustc.edu.cn` 子域（拓扑对照可用 676 节点）；
- 2788 条有向链接的无向投影/有向分析；
- 8115 条 URL 的 HTTP 状态与标题；
- 子域级模板特征（路径签名、扩展名、路径深度）；
- 静态横截面分析；
- 随机失效/蓄意攻击/观测失效的情景模拟。

### Out of scope

- 页面级内容/文本语义（只有标题，没有正文）；
- 用户访问量、点击流、搜索日志；
- 时间演化/增长（只有一次快照）；
- 真实漏洞利用、渗透测试、任何主动扫描；
- “某个子域一定属于某个院系”的因果断言；
- 对学校具体运维决策的强制性建议（只给分析性建议）。

## 4. 方法蓝图

| 要素 | 选择 |
|---|---|
| 研究范式 | 实证主义 / 定量 / 探索性 + 验证性 |
| 数据策略 | 二手公开数据；子域级；横截面 |
| 分析单元 | 子域（节点）；子域对（边）；子域-URL（模板特征） |
| 结构层 | 度/强度/介数/PageRank/HITS/k-core；Louvain/标签传播/GN；模块度/NMI/ARI |
| 模板层 | URL 路径签名 Jaccard；Mantel 检验；强边骨架/disparity filter |
| 健康层 | 真失效（A/D/F）vs 假失效（B/C）；ok_ratio；度保持零模型 |
| 韧性层 | 节点移除（随机/度/介数/PageRank）；GCC/全局效率；观测失效情景 |
| 综合层 | 介数百分位 × (1−可用率) 风险矩阵；四象限治理清单 |
| 效度/稳健性 | 多算法/多 seed；二值/原始/log 权重；671/676 口径；真/假失效两套；人工标注 κ |

## 5. Devil's Advocate 检查

### 5.1 最强的替代解释

| 替代解释 | 如果成立，会怎样 | 我们的应对 |
|---|---|---|
| 死站点度低是因为“死了所以爬不到”，不是“边缘所以没人维护” | 发现 3/7 的因果方向反了 | 主用入度（健康站点指向它）、控制 `url_count`、只写“相关” |
| “部分失效更靠主干”是因为认证型中心服务（wp/zzb）被算作部分失效 | 发现 7 被夸大 | 用 `-1/-2/403` 剔除 69 个，报告校正前/后两套；校正后 GCC 66.7% 仍低于只删全挂的 75.7% |
| 模板相似度是 20 条 URL 上限造成的噪声 | 模板层结论不成立 | 只取 ≥10 条 URL 的 394 子域；三种签名；Mantel 零模型；把“不相关”也当结果 |
| 社区数 23/25 是算法/哈希随机化的产物 | 社区结论不可信 | 设 `PYTHONHASHSEED=0`；多 seed/多算法；报告 NMI/ARI；把“敏感性”本身作为发现 |
| “关键≠脆弱”只是“度大的站点被维护得更好” | 治理建议变成同义反复 | 用介数/PageRank 而不只是度；控制规模；把“为什么核心健康”作为讨论问题 |

### 5.2 “So what?” 检查

如果所有发现都只是描述性的，这个课题还有价值吗？

**有**，因为治理含义是具体的：

- 不要因为“162 个站挂了”就以为网络要瘫——它们大多是叶子，删掉反而更高效；
- 真正要修的是“还在主干上、但一半页面打不开”的 149 个部分失效站点；
- 真正要保护的是 teach/news/en/staff/lib 这几个“当前健康、但一坏就疼”的核心；
- 认证/robots 造成的“假失效”要从监控里剔除，否则巡检资源会被浪费。

### 5.3 逻辑链检查

1. 数据有健康层 → 能区分“结构重要”与“当前可用”；✅
2. 有模板层 → 能检验“社区是不是模板造的”；✅
3. 有鲁棒性曲线 → 能区分“随机/观测/蓄意”三种情景；✅
4. 有零模型 → 能把“失效聚集”从叙事变成可检验假设；✅
5. 有风险矩阵 → 能把分析变成可操作清单；✅
6. 没有时间/流量 → 不能讲“演化/真实影响”；❌（已在局限中声明）

**结论：逻辑链闭合，范围可控，15 天可完成。**
