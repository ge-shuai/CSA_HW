## 汇报的三条结论

1. 在 674 节点无向主分量上，最大连通分量首次跌破原规模一半时，随机均值曲线对应移除 **40.80%** 的节点，按介数排序为 **11.28%**（E3）。
2. 观测失效名单的剩余效率差对随机对照敏感。仅按观测入度分层时，两份名单的差为 **0.0163** 与 **0.0133**，同时限定观测出度为零后均接近零（E5）。
3. 162 个全挂标记站点缺少可见出链，单次抓取无法判定失效站点原本是否更倾向于彼此相连（D4）。

## 补充分析

1. **重尾，但不是幂律/无标度**：幂律 vs 对数正态的 LR=−16.67（p=0.0004），对数正态更受支持；α 随 x_min 1.56→2.75 漂移（A1）。
2. **随机很稳、靶向很脆**：随机 p_c(50%)=40.8%，介数 11.28%，度 11.42%；静态攻击低估动态（介数 f=0.12 差 37.69 pp）（E1/E2/E3）。
3. **治理清单可计算，但只是情景**：下线 123 / 修复 121 / 保护 86 / 监控 5；下线类幸存点对零断连，同 k 随机超出机械项的断连点对平均 33312（G3）。

## 三条最容易被写错的（不要写）

- ❌ “删死站让效率上升”——`E_full` 分母收缩；只看 `E_fixed`。
- ❌ “失效不聚集”——死站出度全 0，死—死相邻构造性不可识别。
- ❌ “25 个社区 / 社区=院系 / 5.2× / 149 个部分失效不加限定”——全部有替代写法，见台账。
