## 0. 一句话判决

**不成立：社区不是院系。** 社区划分与标题类别划分的 NMI = **0.1239**、ARI = **0.019**。
前者对规模匹配的随机基线（0.0628 ± 0.0054）确实显著偏高（z = 11.26，并入观测值的保守 p = 0.001），
但**效应本身只有 0.12**，ARI 几乎为 0；按社区规模加权的类别纯度 **0.4292 vs 随机 0.3997，提升只有 +0.0295**。
更关键的是替代解释：**"同根域前缀"这个纯字符串特征给出的 NMI = 0.1311，比类别的 0.1239 还高**
（`summary:alternative_features_top`）→ 社区的"语义感"至少有同等部分来自**域名命名习惯**而不是组织归属。
另外分类器本身**弱**：38.0% 的站点落进"其他"，三种拆分方案下 κ = 0.456 / 0.367 / 0.248，
只在信息量充足的 449 个站点子集上重算也只有 κ = 0.312 / 0.192 / 0.065。

但**"没有语义"不等于"没有结构"**：类别层面的**度同配是正的**（Newman r = 0.0201，z = 2.69，p = 0.007），
其中 **7 个类经 BH 校正后显著**，而且**"院系"类是显著负同配（r_j = −0.0975，z = −4.81，p < 1e−3）**
→ 院系站**回避**互相链接，这本身就是 §2.3 里那条"高收入节点是分发型而非互连型"（A5 无反富俱乐部）的语义版本。

**BH 显著类数 = 7**（`summary:n_sig_bh_05`），其中 **6 正 1 负**。

两条判决性观察：
1. **"院系"是最大的边份额类（a_j = 0.2489），但它的边里只有 17.57% 留在院系内部**（低于其份额期望）
   → 院系站**向外**链接，不互相链接。这与 A5 的"无 rich-club、φ 反而低于度保持零模型（z=−2.65）"
   以及度同配 −0.167 同向、互相印证：**这张图的组织方式是"门户 → 分散叶子"，不是"院系内部成团"。**
2. **"科研平台"（185 站，最大的真实类）与"其他"（255 站）都不显著**
   → 显著的正同配全部落在 n ≤ 75 的小类上，其中 4 个类 n ≤ 11。
   小类的 r_j 天然方差大（置换 sd 已达 0.017–0.018），**这些正号的可重复性弱**，
   引用时必须带 n（本表已带）。

### 4.3 一个必须写清的恒等式检查

"只在同类内部重排标签"对 (e_jk, r) 是**恒等变换**（不改变任何一条边的端点类别），因此它**不能当零模型**。
本模块把它降级为 sanity check，实测两侧都是 0.020144（`summary:assort_within_class_perm_is_identity = [0.020144, 0.020144]`，断言通过）。
真正的零模型是**类别规模不变的跨类重排**（1000 次，每次 fresh permutation，§4/§8）。

> 修过的 bug（记录以免被当成结论）：`run_b6.py` 原先把"组内重排"写成 `nc[perm(ix)] = ix`，
> 会把**节点下标**（0–670）写进**类别编码数组**（0–9），触发 `IndexError: index 71 is out of bounds for axis 0 with size 10`。
> 已改为 `nc[perm(ix)] = nc[ix]`。改完才通过恒等断言。

  但即便在最干净的子集上，ARI 0.037 也远谈不上"社区=院系"。
- z 从 11.26 降到 10.51：子集更小但基线也更宽（0.0902 vs 0.0628）。

## 6. 替代解释（`alternative_features.csv`）

与社区划分（seed=42）比 NMI 的其他特征分区，置换重复 500 次：

| 特征分区 | NMI | z | p | ARI |
|---|---|---|---|---|
| **同根域前缀（模板/CMS 线索）** | **0.1311** | 4.367 | 0.000 | 0.0030 |
| 类别（本模块基线，10 类） | 0.1239 | **11.257** | 0.000 | 0.0190 |
| status_codes 指纹 | 0.0728 | 4.572 | 0.000 | −0.0013 |
| protocol（https/http） | 0.0451 | 10.289 | 0.000 | 0.0137 |

⚠ **不要横着比 z**：z 的分母是各自的 null sd，而 null sd 由类别数决定
（"同根域前缀"有 70+ 个取值 → null NMI 更宽 → 同样 NMI 下 z 更小）。
**可比的是 NMI 与各自 null 的比**：按根域前缀（1.9×）与按类别（2.0×）给出的结构信号**同等量级**。

→ 这条是本模块最有力的否定性证据：**一个纯粹来自 URL 字符串的域名前缀特征，
和社区结构的对应程度不输"组织类别"**。所以社区不能解释成"院系聚成团"，
更合理的解释是**命名/托管习惯 + 门户指向**（与 B5 的枢纽边敏感性、F2 的模板家族一起看）。

## 8. 局限

1. **分类器弱**（κ 上限 0.456，38% "其他"）→ 类别是**代理变量**，不是院系的真值。本节否证"社区=院系"，
   但不能等强地说"社区无意义"：真值缺失时二者不可分。
2. **173 个失败页标题同时污染类别与失效统计**（§1.1）：任何"类别 × 健康"的关联都含共同缺失机制。
3. **NMI 对类数敏感**（§5）→ 只用相对各自 null 的比下结论。
4. **小类方差大**：4 个显著正同配类里 3 个 n ≤ 11，其 r_j 的置换 sd 已与 r_j 同量级。
5. 单次横截面、无时间、无流量（§7）：全文只用"与…相关 / 结构上对应"，
   **不得**写成"因为同属一个院系所以互相链接"。
6. `purity` 的 max = 1.0 来自极小社区（单点/两点），**不是**发现了一个纯社区；引用纯度请只用规模加权值。
