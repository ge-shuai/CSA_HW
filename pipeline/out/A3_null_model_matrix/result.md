# A3 · 生成模型对照矩阵（ER / WS / BA / 度保持配置模型）

口径：无权无向二值图；主口径节点集 **671 有属性节点**（CONVENTIONS §1 主表必须 671），敏感性口径 676（含 5 个悬空）。开跑先 `C.assert_anchors()` → 31/31 PASS。
观测图（671）：n=671，m=2493 条无向边，平均度 7.4307（676 口径 7.3905 = CONVENTIONS 锚点值），最大度 119（`teach.ustc.edu.cn`），度 Gini 0.6156，连通分量 2 个（GCC 669，另有 [2] 的小分量）。
实例数：主模型 40／敏感性 30／WS 扫描每个 p 30；全部固定 seed（`SEED=20261113`+模型偏移+实例号，见 `RUN.txt`）。耗时 454s。

## 0. 连通性处理规则（判据要求写明）

1. **路径类指标（`aspl_gcc` 平均最短路径、`diameter_gcc` 直径）只在每个实例自身的最大连通分量（GCC）上计算**；其余 8 个指标在该实例的全图上计算。
2. 这条规则**同时作用在观测网络和每一个模型实例**上，两边口径对称。
3. `gcc_fraction`（最大分量节点数 / 该实例节点数）单独作为一个指标报出，把「非连通程度」本身纳入判决，而不是被路径指标偷偷消化掉。
4. 每个模型的连通／非连通实例个数见 §6，并在 `verdict.csv` 的 `n_connected_instances` / `n_disconnected_instances` 列里。
5. 平局规则：最大分量规模相同者并列时，取 `networkx.connected_components` 的返回顺序第一位；实测本次所有实例与观测图的最大分量规模均唯一。
6. 观测网络自身在 671 口径下有 2 个连通分量（GCC=669，`gcc_fraction`=0.9970），所以观测侧的路径指标是在 669 个节点的 GCC 上算的。

## 1. 综合判决规则（先说规则，再给结论）

**主判据**：`rms_z_core4` 升序 = sqrt(mean(z²))，z=(obs−mean_model)/sd_model，在 4 个「跨模型自由指标」CORE4 = {平均聚类系数, GCC 平均最短路径, GCC 直径, 度同配性} 上聚合。这就是判据点名的标准化距离口径。
**三条一致性检验**（全部留在 `verdict.csv`，用来检查主判据是不是只是 sd 的产物）：
- a) `n_core4_explained`：CORE4 里 |z| ≤ 2 的个数（越大越像），刻度粗但不受 sd 大小影响；
- b) `rms_reldev_core4` = sqrt(mean(((obs−mean)/obs)²))：纯效应量，与实例分布的宽窄无关；
- c) `mahalanobis_D_core4`：把 4 个指标之间的相关一起用进去的多元距离（样本协方差 + 伪逆）。
**判决纪律**：只有当主判据与 a/b/c 给出**同一个第一名**时，才写「最像 X」；否则本单元判「无法判定」并把分歧如实列出。2–4 名的顺序不作为结论。
为什么主判据只放 4 个指标：度 Gini / 最大度 / α 对配置模型**由构造恒定**（度序列被逐点保持），把它们塞进跨模型平均等于让配置模型白拿满分；`n_nodes`/`mean_degree` 是参数匹配目标。8 个判别指标在 §2/§4 逐指标列全，配置模型的恒等指标在 `metric_class` 里标为 `invariant_by_construction`，并从它的 `rms_*_free8` 中剔除。
为什么还要 b：n≈670 时各模型的实例分布**极窄**（`cv_sd_over_mean` 列，常见 0.5%~5%），纯 z 排序会偏向 sd 大的模型，所以每次都给出不依赖 sd 的效应量对照。

## 3. 判决结论

### 3.1 四种跨指标聚合给出的排序（判决只取第一名的共识）

| 聚合口径 | 排序（最像 → 最不像） | 第一名 |
|---|---|---|
| 主判据 `rms_z_core4` | `ConfigModel_degreePreserving` < `WS_k8_p0.05` < `BA_m4` < `ER` | `ConfigModel_degreePreserving` |
| `n_core4_explained` | `ConfigModel_degreePreserving` < `ER` < `WS_k8_p0.05` < `BA_m4` | `ConfigModel_degreePreserving` |
| `rms_reldev_core4` | `ConfigModel_degreePreserving` < `BA_m4` < `ER` < `WS_k8_p0.05` | `ConfigModel_degreePreserving` |
| `mahalanobis_D_core4` | `ConfigModel_degreePreserving` < `WS_k8_p0.05` < `BA_m4` < `ER` | `ConfigModel_degreePreserving` |

**判决（一句话，可复算）**：在 671 主口径、四个模型各 40 个实例、8 个判别指标、四种跨指标聚合下，与观测网络结构最接近的是 **`ConfigModel_degreePreserving`**（rms_z_core4=16.336，rms_reldev_core4=0.3298，CORE4 的 4 个指标里 1 个 |z|≤2）。这个「最接近」**仅是排序意义**：`ConfigModel_degreePreserving` 自己仍有 3/8 个判别指标 |z|>2（§4）。
2–4 名的顺序在四种聚合之间互相调换（z 口径 `WS_k8_p0.05` < `BA_m4` < `ER`；效应量口径 `BA_m4` < `ER` < `WS_k8_p0.05`），所以本单元只对第一名表态，不对中间名次表态。

### 3.2 明确的否证

1. 「观测网络属于 BA 那一类（增长 + 优先连接）」在这张表里**没有支撑**：BA 有 8/8 个判别指标 |z|>2，逐指标数值见 §5；而且本数据没有时间序列，BA 的两个机制假设根本不可检验（§9.1）。
2. 「观测网络是度保持随机图」同样不成立：配置模型的平均聚类系数 z=+31.9（观测 0.2801 vs 实例 0.1040，观测是实例均值的 2.69 倍）。
3. 「小世界 = WS 就够了」不成立：WS(p=0.05) 的聚类系数是观测的 1.98 倍、GCC 平均路径是观测的 1.74 倍，两头都偏；把 p 扫到 §7a 的 10 格，也没有任何一格把两者同时拉进 |z|≤2。
4. 没有任何模型在 8 个判别指标上全部 |z| ≤ 2。逐模型未解释指标个数：`ConfigModel_degreePreserving`=3, `WS_k8_p0.05`=8, `BA_m4`=8, `ER`=7。

## 8. 每个数字可指到哪儿

- 指标定义：`run_a3.py:all_metrics()`；Gini `run_a3.py:gini()`；α `run_a3.py:pl_alpha()`；路径一次遍历 `run_a3.py:path_mean_and_diameter()`（与 `networkx.average_shortest_path_length`/`nx.diameter` 在观测 GCC 上做过等值断言，见 `RUN.txt`）
- 参数匹配：`run_a3.py:make_models()`（ER 的 p=2m/(n(n−1))；WS 的 k=round(平均度/2)×2；BA 的 m 由 `run_a3.py:ba_m_for()` 解 m(n−m)=|E| 取整）
- 配置模型：`run_a3.py:config_model_instances()` → `csa_common.degree_preserving_null`（nswap=10·|E|、max_tries=100·nswap、每轮 fresh copy；本脚本对「挂钩实例批 == csa_common 统计实例批」和「度序列保持 / 无自环」都做了断言）
- z、双侧经验 p、零方差处理：`run_a3.py:summarize()`；RMS `run_a3.py:rms()`；多元距离 `run_a3.py:mahalanobis()`；排名规则 `run_a3.py:rank_primary()`
- 机器可读：`null_model_matrix.csv`（指标×模型×口径）、`verdict.csv`（判决全部列）、`instances.csv`（每实例 10 指标 + 连通性 + 实际 seed，可逐行复核）、`observed_and_config.json`（观测值与所有参数）、`RUN.txt`（环境/耗时/seed 方案）

## 9. 局限（与结论同等重要）

1. **这是结构相似性比较，不是生成机制的证据。** 数据是单次横截面，没有时间序列，无法检验「节点增长」与「优先连接」这两个 BA 的核心机制假设；本表只能说某个静态拓扑快照与某个模型的样本在这几个指标上更接近，**不能**说网络按该模型的方式长成这样。
2. z 是标准化距离，不是模型证据强度；RMS 是描述性平均，CORE4 内部（聚类／路径／直径）彼此相关，综合分数没有概率解释。Mahalanobis 距离把相关一起用进去，可能与 RMS 给出不同顺序，两个都已在 `verdict.csv`。
3. n≈670 时各模型的实例分布很窄（`cv_sd_over_mean` 列给出），|z| 动辄几十上百，**只能用于模型之间的横向比较，不能当成「显著性」的度量**；双侧经验 p 的分辨率下限 = 1/实例数 = 0.025（主模型 40 个实例），`p_two_sided=0` 只表示「40 个实例里没有一个偏离得比观测值更远」。
4. 参数取整误差不可消除：WS 的 k 只能取偶数、BA 的 m 只能取整数，两者都无法把平均度精确匹配到 7.4307；差值在 §5a 与 `verdict.csv` 里显式给出，并配了反方向取整与随机修剪变体作对照。
5. 边交换零模型在一般图上是**非均匀采样**（Viger & Latapy 2005，已在 `csa_common.degree_preserving_null` 的 note 里声明），配置模型的 sd 与 p 是近似的；交换是否充分无法严格证明，只能观察边改动比例（本次实测见 RUN.txt）。
6. 幂律 α 固定 `x_min=3`：这只是各模型同口径下的一个汇总统计量，x_min 的选择、拟合优度、与对数正态/指数/截断幂律的比较属于 A1，不在本单元判决范围。
7. 模型均为**无权无向**图：边权异质性、有向性、以及 162 个整站不可用节点出度全为 0 的删失（CONVENTIONS §2.1/§2.2）都不在本矩阵覆盖范围内；有向结构的模型对照属于 A4。
8. 观测图有 2 个连通分量（GCC 669 + 一个 2 点分量），ER/WS/BA 的绝大多数实例是单连通的 —— 这个差异本身被记在 `gcc_fraction` 指标里参与判决。
