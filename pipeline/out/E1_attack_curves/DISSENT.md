## 3. 结构性理由：无权无向 PR 不是一个独立策略

在无向图上，PageRank 的转移只通过 `deg_i`（无权）或 `strength_i`（加权）进入，teleport 项只造成
一个仿射修正，所以排名与度/强度排名高度重合。实测（674 基准图）：

- ρ_spearman(PR_无权无向, degree) = **0.977**，τ_kendall = **0.903**；
- Top-k 名单重合率：k=34 → 0.912，k=67 → 0.940，k=135 → 0.941，k=202 → 0.921；
- 曲线几乎重合：55.19/3.56/0.59 vs 度攻击 57.57/4.45/1.04，差异在同值组换序造成的范围内
  （本模块平手敏感性表 `e1_tiebreak_sensitivity.csv`：度曲线同值换序极差 0.74 pp @f=10%、
  8.75 pp 最大）。

结论：**"无权无向 PageRank 攻击"实质是度攻击的另一种写法**，它给出的是"最疼"的曲线之一，
而不是 §5 表暗示的"较温和的对照"。这对 §5 的定性判断没有威胁（见第 4 点），但会让任何
按契约数值去复算的人得出"PageRank 对照比度攻击温和"的**反向**印象。

## 4. §5 的核心告诫在本数据里成立（而且更强）

主口径下 PageRank 攻击确实远弱于度/介数攻击（同一 k，f=20%）：
`pagerank_dw` GCC 57.7% vs 度 4.5% / 介数 13.2%；E_fixed 0.0824 vs 度 0.0024 / 介数 0.0045。
但把"无权无向"作为对照时，它比度攻击还略狠（3.56% vs 4.45%）。因此正文必须写成：
**"PageRank 攻击远弱于度/介数"只在有向加权口径下成立；无权无向口径不但不是温和对照，
反而与度攻击等价**。这正是 §5 想防止的误读，本模块把它量化了。
