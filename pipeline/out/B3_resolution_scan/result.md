## 0. 一句话判决

**"25 个社区"是 γ=1 这一个取值的产物，不是网络的内在尺度。**
γ 从 0.05 升到 3.0，非单点社区数从 **4.15 单调升到 39.95**（Spearman(γ, n_ns) = **+1.0**，p = 0.0，`verdict:spearman_gamma_vs_n_ns`）；
而 γ=1 划分的**任何一对社区**都没有在 γ > 1 时被预测会分开（`verdict:n_ref_pairs_by_gamma_star['>1'] = 0`，
最晚分离的点对预测阈值 **γ\* = 0.9613**，`verdict:max_gamma_star_ref_pairs`）。
同时"用 Q 最大来选 γ"在这个数据上是**错**的：Q 在自己的尺度上 argmax 落在 **γ = 0.05**（`verdict:argmax_Q_same_null=0.05`），
只有把各 γ 的划分**统一回到 γ=1 尺度重新打分**，argmax 才回到 **1.0**（`verdict:argmax_Q_rescored_at_gamma1=1.0`）。

好消息是：γ=1 附近确实有一个**局部**最优区，但它的宽度只有 **Δγ ≈ 0.1–0.3**，
而且这个宽度**恰好等于 seed 噪声本身**（§3）。

三条读法：

   → 这是模块度在低分辨率下的**定义性偏好**（合并总是提高同尺度 Q），不是"网络在 γ=0.05 更像 4 块"。
2. **重打分 Q 在 γ≈1.0–1.1 处是平的**（0.6902 / 0.6902），两侧都低（γ=0.9 给 0.6896、γ=1.2 给 0.6895）。

3. **社区数 sd 只有 0.67–1.93**，而整个 γ 区间里均值涨了 35.8 → 分辨率效应比 seed 效应大一个数量级。
   **γ 是本分析里比随机种子更值得报告的控制量。**

## 2. 平台宽度（`verdict:plateau_*`）

以"与 γ=1 划分的 NMI 不低于阈值"定义平台（coarse / fine 两种网格结果相同）：

| 阈值 | 绝对 NMI 平台区间 | 相对 seed 天花板平台区间 |
|---|---|---|
| ≥ 0.98 | **[1.0, 1.0]**（只有 γ=1 自己） | [1.0, 1.1] |
| ≥ 0.95 | [1.0, 1.0] | [0.9, 2.2] |
| ≥ 0.90 | [1.0, 1.1] | [0.7, 3.0] |
| ≥ 0.85 | [0.9, 2.3] | — |
| ≥ 0.80 | [0.7, 3.0] | — |

- 绝对口径下 47 档里只有 **1 档** NMI ≥ 0.90、**32 档** < 0.90（`verdict:n_gamma_nmi_ge_0.90=1` / `n_gamma_nmi_lt_0.90=32`）
  → **γ=1 是一个尖峰，不是一个平台。**
- 社区数落在 γ=1 的 ±2sd 带内的 γ 只有 **5 档**（`verdict:n_gamma_ns_within_2sd_of_ref=5`，区间 **[0.8, 1.2]**）。
- 用 seed 天花板归一化后平台明显变宽（≥0.95 → [0.9, 2.2]）：
  这说明**"NMI 掉了"和"划分真的变了"不是一回事**，γ>1.1 的下降有一部分是"两个本来就互不相同的 seed 集合之间的自然离散"。
  两种口径都给，是刻意的（§0 的判决取严格的那个）。

## 3. 没有相变

- `verdict:phase_transition_gamma_list_coarse = []`、`_all_ladder = []`，
  47 档的 `phase_transition_flag` 全为 **0**（阈值取 4.08 = 2×合并后的 seed sd，见 `resolution_stability.csv` 的
  `dn_ns_per_dgamma` 与 `phase_transition_threshold_dN` 列）。
- 最大斜率出现在 γ = 0.25（`dn_ns_per_dgamma = 70.0`，即每单位 γ 涨 70 个社区，对应最大社区从 586 → 387 的骤降段），
  但**仍低于相变阈值**。
- 共识熵在 γ ∈ [0.25, 0.30] 处达到峰值 **0.5436 bit**（`consensus_entropy_bits`），
  该处最大社区的 seed sd 高达 **85.8**（对比 γ=1 的 12.9）→ 中段是最**不确定**的区域，不是"发现了新结构"。
- 结论：社区数随 γ **连续**增长，没有临界分辨率。**任何"选 γ=1 因为那里有自然断点"的说法在本数据上站不住。**

## 4. 分辨率限制的定量核对（Fortunato–Barthélemy 2007）

| 量 | 值 | 单位 | 来源 |
|---|---|---|---|
| 无权 FB 尺度 √(2m) | **70.7** | 节点数 | `verdict:fb_scale_sqrt_2E_unweighted`，m = 2498 |
| 加权 FB 尺度 √(2S) | **355.7** | **强度**（非节点数） | `verdict:fb_scale_sqrt_2S_weighted`，S = 全图总强度 |

⚠ **单位警告**：这两行不可互相比较，也不可只挑大的那个和节点数比。
√(2S) 的量纲是边权和的平方根，本数据总强度 ≈ 6.3 万（CONVENTIONS §1 的 `bs→som` 4870 = 7.7% 反推 ≈ 63,200，一致）。
与社区**节点数**可比的是 √(2m) = 70.7。

按可比的 √(2m) = 70.7 判断：γ=1 时最大社区 93.75 个节点（671 非单点口径）在阈值之上，
其余社区全部落在 **√(2m) 以下**（γ=1 的非单点社区平均规模见 `resolution_summary.csv` 的
`mean_size_nonsingleton_mean` 列）→ **按 FB 判据，本网络的绝大多数社区处在模块度原理上无法分辨的区间**。
这与 §1 观察到的"γ 一动社区数就连续变化"完全一致。

自校验：本模块自己实现的 Q 与 `nx.community.modularity` 的最大绝对差 = **0.0**，
ΔQ 公式差 = **0.0**（`verdict:selfcheck_Q_formula_vs_nx_absdiff` / `selfcheck_dQ_formula_maxabsdiff`）
→ §1 的 Q 数字与 B1/B2 可直接对照。

## 5. 合并/分裂事件（`merge_split_events.csv`、`pair_merge_threshold.csv`）

- γ=1 参考划分的社区点对共 223 对可用（`verdict:pair_curve_n_ok_pairs=143` 为进入拟合的子集，
  另有 21 对在网格下界 0.05 处就已分离，`verdict:pair_curve_status_counts`）。
- 预测阈值分布（`verdict:n_ref_pairs_by_gamma_star`）：
  **γ\* > 1 的对数 = 0**、(0.8, 1] = **4**、(0.5, 1] = 23、(0.25, 1] = 65。
  → 全部点对的预测分离阈值都在 γ=1 **以下**，最晚的一对 γ\* = 0.9613。
- 预测 vs 实测：中位绝对偏差 **0.1119**、中位带符号偏差 **−0.0279**（`verdict:pair_curve_median_*`）。
  带符号偏差为负 → FB 公式**略微高估**了分离所需的 γ，即实际比预测更早分开。
  Pearson r = **NaN**（`verdict:pair_curve_pearson_r_pred_vs_emp`）：实测阈值高度并列（多数点在网格上取到同几档），方差为 0，
  **不要把 NaN 读成"没有关系"，这里是"不可计算"**，改看中位偏差。
- 分裂事件：强分裂事件 **1 个**，且 **0 个**发生在 γ=1 附近（`verdict:n_strong_split_events` / `_touching_gamma1`）；
  预测落在扫描区间内的事件占比仅 **16.67%**（`verdict:events_pred_inside_interval_frac`）。
- 对 7 个参考社区（编号 18/23/26/41/46/80/84）内部 13 个点对做"随 γ 升高是否被拆开"检查：
  **实测拆开的对数 = 0**（`verdict:intra_ref_split_n_emp_split_gt_1`），而预测 γ\* ≤ 1 的有 4 对。
  → γ 升高带来的社区数增长**主要来自重新组织边界与孤立点归并，而不是把 γ=1 的社区整齐地二分**。
  这条对报告很重要：**不能把"γ 大了社区变多"讲成"看到了更细的层次"。**

## 7. 局限

1. 20 个 seed 是**下界**：B1 显示社区数范围 23–26，本表每档的 sd 已接近 1.4，阈值的经验误差不小于 0.05 档。
2. NMI/ARI 用 `csa_common.partition_metrics`（覆盖交集上重编号）；γ 很小时大量节点被并成大社区，交集恒为全图，
   但**跨 γ 的 NMI 比较隐含"以 γ=1 为真值"**，这是刻意的（问题就是"离开 γ=1 会怎样"），不是无偏度量。
3. FB 判据是给**未加权 / 稀疏**图推导的，加权版本沿用 √(2S) 属常规做法但严格性有限（§4 的单位警告）。
4. `pair_curve_pearson_r` 因实测阈值并列而不可计算，点对层面只报中位偏差。
5. 单次横截面数据，本节全部是**口径敏感性**，不涉及任何因果断言（§7）。
