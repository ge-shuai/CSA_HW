## 2. 必须回答：模板相似 ↔ 超链接相邻，到底有没有关系？

**答：没有实质关系。** 论据按重要性排序：

1. **效应量可以忽略**：主口径 671 上，最"显著"的 S1 Jaccard×binary 只有 r=+0.0419（CI 上界 0.069）。把 r 换算成"可达上限的占比"（`r_ceiling_pos` = 在 1.11% 边密度 + 该相似度分布下能取到的最大正相关）：S1 是 0.060、S2 是 0.131、S3 是 −0.024。也就是说模板相似度最多解释到 adjacency 的百分之几，**不是"弱但有意义"，而是"接近噪声"**。
2. **加权口径基本不成立**：6 个主检验里 `adj_weighted` 的三个 r 分别是 0.0154、0.0028、0.0007；S2 的 p=0.2556、S3 的 p=0.7414，bootstrap CI 都跨 0（`F:bootstrap_vs_perm.csv`）。加权邻接是"观察到的链接次数"，如果模板真的驱动链路，加权口径应当更强，事实相反。
3. **S3（路径指纹）方向不稳且为负**：Jaccard 版本 r=−0.0061(p=0.395)，Hamming 版本 r=−0.0367(p=0.0000，CI 完全在 0 以下)。Hamming 是"相似"度量，负相关意味着**模板越像、越不容易连**——与"同模板⇒同平台⇒互链"的假设方向相反。这条负号不应被解释为"模板排斥"，只能是"没有正关系"的另一种写法。
4. **子样本一换，全部消失**：在 `listed_urls>=10` 的 394 站敏感性口径上（`F:mantel_grid.csv:node_set=eligible394`，`c:370`），6 个主检验 r 落在 −0.0065…+0.0093，p=0.0365–0.6803，5/6 不显著。**所以主口径那点 r 不是稳定的结构信号，而是 671 池里大量"根页面单点站"（`F:structure_visibility.csv`：277 站 `listed_urls<10`，142 站只有根页面）造成的**。
5. **`spd_hops` 上的相关不能当作模板效应**：S1 的 r=−0.164、S3 的 r=+0.264 看起来大，但 `F:covariance_decomposition.csv` 显示协方差被单点主导——S1 的最大贡献节点 `wpsearch.ustc.edu.cn` 一家占 0.243、前 10 个节点占 0.697；S3 的 `lib.ustc.edu.cn` 占 −0.224、前 10 个占 −2.135（符号翻转）。即这两个数是"某几个站点在距离矩阵里的位置"的函数，不是模板层的性质。

**一句话**：模板相似度与超链接相邻在本数据里**没有可解释的关系**（|r|≤0.043，≤13% of ceiling，子样本上消失）。

## 3. 关键坑的显式回应

**（坑 1）置换零模型必须独立重复、参数合规。**
- `n_perm=1999`，每个 replicate 重新同时打乱行/列标签（RUN.txt 第 5 行、`c:280`）；未使用累积交换。报告 `null_mean`、`null_sd`、`z`、双侧经验 p（`F:mantel_grid.csv`）。
- 置换 null 的 sd 与 bootstrap se 差 0.69–9.79 倍（`F:bootstrap_vs_perm.csv:ratio_boot_over_perm`），说明**置换 null 低估了抽样不确定性**（置换只重排标签、保留边际，因此低估了抽样不确定性），所以显著性判据以 bootstrap CI 为准，p 值只作辅助。

**（坑 2）"显著"必须配效应量与上限。**
- 224785 个点对、2493 条边（边密度 1.109%，`F:structure_visibility.csv`）→ 任何 r≥0.01 都会 p<0.01。本单元所有 p<0.05 的结果都同时给了 `r_ceiling_pos/neg` 与 `r_over_ceiling`；正文只允许引用 r 与 CI，不允许只引 p。

**（坑 3）签名本身的稀疏性会限制可判别性（这是 F3 的输入）。**
- `F:signature_audit.csv`：`S1_tok_jaccard` 有 84.12% 的点对相似度为 0、只有 92 个不同取值、142 个站点的 token 向量为空；`S3_tmpl_hamming` 的 pair_mean=0.9709、99.0% 的点对 >0.90、只有 33 个不同取值。**S3 Hamming 的"相似"几乎没有方差**，其 Mantel r 的解读必须打折扣。
- CMS 指纹几乎全部为空：`F:cms_marker_audit.csv` 里 `/wp-content/`、`/dede/`、`/plus/`、`/sites/all/`、`/_next/` 等 0 命中，唯一的真实信号是 `/list.htm`（3887 条路径 = 47.90%）与 `/index.php`（68 条 = 0.84%）。所谓"扩展名/模板指纹"在本数据里只等价于"是不是那套 list.htm 列表页"，这限制了 S2 的信息量。

**（坑 4）删失结构限制了"模板→链接"的可观测面。**
- `F:structure_visibility.csv`：82458 个点对（36.68%）的一方是死站、死—死点对 13041 个（5.80%），**42.48% 的点对至少含一个死站端点**；死站一侧的出边完全不可观测（CONVENTIONS §2.1）。所以"模板相似但没连"有相当一部分根本不可观测，本单元的 r 是对**可见部分**的估计。

## 4. 与 MANIFEST 预期值的对照（不是矛盾，是校准）

MANIFEST 的"已知 r≈0.00–0.01、p≈0.09–0.22"来自更早的探索；本次实测在同一量级但不完全相同：`adj_weighted` 与 eligible394 子集基本落在该区间（0.0007–0.0154，p 0.037–0.741），而 `adj_binary` 的 S1/S2 把它顶到 0.018–0.043 且 p≈0。结论方向不变（无实质关系），引用时应使用本文件的实测值而不是 MANIFEST 的预期值。
