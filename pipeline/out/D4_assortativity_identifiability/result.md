## 0. 判决

1. **"失效不聚集"在本数据里不可识别，不是阴性结果。** 死—死相邻的可观察样本点 = 0：13041（run_d4.py:L169） 个死—死无序点对（26082（run_d4.py:L168） 个有序对）要成立，必须有一条**从死站出发**的弧；而源为死站的点对共 108540（run_d4.py:L166） 个（占有向点对 24.143（run_d4.py:L171）%）观察概率为 0，观测到的从死站出发的边 = 0（run_d4.py:L125）（162（run_d4.py:L129）/162（run_d4.py:L110） 个死站出度为 0，最大出度 0（run_d4.py:L130））。观测 e_DD = 0（run_d4.py:L194） 与"零条边从死站出发"是同一件事的两种写法。
2. **那个 p<0.001 重采样的是"零模型能不能造出不可观察构型"。** 固定度序列时混合矩阵三格由 e_DD 单变量决定 ⇒ 同配性是 e_DD 的仿射函数，实测 ρ = -0.06300553（run_d4.py:L236） + 0.00718247（run_d4.py:L235）·e_DD，500（run_d4.py:L216） 轮上 R² = 1.00000000（run_d4.py:L237）、最大残差 2.78e-17（run_d4.py:L238）。观测值对应 e_DD≡0（ρ=-0.063006（run_d4.py:L183）），零模型 e_DD 最小 1（run_d4.py:L229）、众数 7（run_d4.py:L233）、均值 7.7080（run_d4.py:L231），500（run_d4.py:L216） 轮里 e_DD=0 的比例 = 0.000000（run_d4.py:L232）。整张显著性表量的就是这个缺口。附带：300 轮置换的经验 p 可分辨率下限是 1/301 = 0.003322（run_d4.py:L276），"p<0.001"在他们的设置里取不到。
3. **改到可观察通道后，差值很大但方向不可定。** 活站发出的 2783（run_d4.py:L352） 条弧中落到死站的占 10.636004（run_d4.py:L360）%（95% CI [9.544356（run_d4.py:L535）, 11.836173（run_d4.py:L536）]%），目标中性基准 24.179104（run_d4.py:L364）% → 比值 0.4399（run_d4.py:L541）、OR 0.3740（run_d4.py:L537） [0.3019（run_d4.py:L538）, 0.4632（run_d4.py:L539）]；但把基准换成站点规模（url_count 加权）后期望只有 1.316098（run_d4.py:L501）%，同一观测值反而**高出**基准 8.081（run_d4.py:L502） 倍。可用规模代理本身对死站删失（死站 url_count 均值 2.228（run_d4.py:L503） vs 健康站 55.564（run_d4.py:L504），差 24.9（run_d4.py:L507） 倍），所以"回避"这个方向**不能写**。

三点补充：

1. **有向版更彻底：方差恒为 0。** 保持 (入度, 出度) 序列的零模型（`directed_configuration_model`，20（run_d4.py:L267） 轮，seed=20261113+7919r）里，从死站出发的弧数恒为 0（run_d4.py:L268），落进死站的弧数恒在 296（run_d4.py:L269）–296（run_d4.py:L270）（sd 0.0000（run_d4.py:L271），只剩重数/自环抖动）。也就是说**观测度序列本身已经把 e_DD 与 e_AD 写死**，检验根本不存在（这正是 §2.1 说的"度保持救不了"）。
2. **p 的算法也不合 §4。** `extra.py:59` 用的是 `(np.abs(vals) >= abs(obs)).mean()`——把"|vals|≥|obs|"当尾概率，而不是"偏离 null mean 的绝对值"。零模型均值本来就离 0 很远（-0.007643（run_d4.py:L218）），这条式子会让计数器直接归零，于是写成 p<0.001。按 §4 重算：**z = -3.136（run_d4.py:L220）、双侧 p = 0.002000（run_d4.py:L221）**（加一平滑 0.003992（run_d4.py:L227））——连 0.001 都够不着，剩下的差异全部来自上面那条 e_DD 缺口。
3. **他们的实现还有 §4 那条老毛病**：`extra.py:51-57` 在同一个 `H` 上连做 300 次 `double_edge_swap(nswap=500, max_tries=20000)`，把累积轨迹当 300 个独立样本，且 nswap 远小于 10|E| = 24970。本模块用 `C.degree_preserving_null` 重做（每轮从原图复制再交换）。

## 4. 这个版本能说什么、不能说什么

**能说（同一份数据、同一口径下可复算）**

- 活→死份额 10.636004（run_d4.py:L360）% 明显低于"目标中性"基准 24.179104（run_d4.py:L364）%（4000（run_d4.py:L379） 轮置换，z = -17.153（run_d4.py:L384））。这个量分子分母都可观察，**没有**被 §2 的删失构造性决定。
- 校正前后同号（10.636004（run_d4.py:L360）% → 7.683742（run_d4.py:L475）%），不依赖 32+1 个未证实节点（§2.2）的归属；点对级（z = -14.2）与加权级（z = -4.4）同向。

**不能说**

- **不能读成"回避"。** 均匀候选池假设"任何站点被链接的概率相同"，这不成立：链接本来就集中在少数站。基准换成 url_count 加权后，期望只剩 1.316098（run_d4.py:L501）%，同一观测值反超基准 8.081（run_d4.py:L502） 倍——**符号完全由基准选择决定**。而 url_count 对死站本身就是删失的（2.228（run_d4.py:L503） vs 55.564（run_d4.py:L504），死站只占全库 URL 的 1.273548（run_d4.py:L506）%），不能当外生暴露量；标签安慰剂 T2（允许热门节点被抽进假 D）给出中间基准 24.156425（run_d4.py:L492）%（null 95% 区间 [529.0（run_d4.py:L493）, 832.0（run_d4.py:L494）] 条弧，z = -4.8）。三个基准没有一个有"状态无关"的辩护。
- **反向读法同样成立（§7：结构 ↔ 健康，不是结构 → 健康）。** 被链接少与缺维护/下线在横截面上互相包含，本数据没有时间轴，无法分离。
- **它测的是抓取轮次里的页面链接混合比。** 分子只统计"被抓到的页面上出现的链接"；指向死站的链接是否仍留在源页面上，取决于源页面自身的抓取与人工维护。
- **互指补偿单独就能压低这个份额。** 死站出度 ≡ 0 ⇒ 活—死弧不可能成对，而活—活弧有 290（run_d4.py:L371） 对互指被计两次（活—活弧互指率 11.660635（run_d4.py:L374）%，活—死弧 0.000%）。点对级检验折叠互指后份额为 11.873245（run_d4.py:L373）%，说明该通道存在但不是全部解释。

**给报告正文的替换写法（原句"失效不聚集 p<0.001"）**

> 死—死相邻在本数据源上的可观察样本点为 0（13041（run_d4.py:L169） 个死—死点对全部要求"死站出链可观测"，实测从死站出发的边 0（run_d4.py:L125） 条），因此"失效同配性"在这里不可识别：观测统计量 -0.063006（run_d4.py:L183） 与度保持零模型 -0.007643（run_d4.py:L218） 的差异由 e_DD 这一格单独驱动（ρ = -0.06300553（run_d4.py:L236） + 0.00718247（run_d4.py:L235）·e_DD，R² = 1.00000000（run_d4.py:L237）），而 e_DD 只能取 0。改在可观察的活→死通道上检验：活站发出的弧中 10.636004（run_d4.py:L360）% 落到死站，OR 0.3740（run_d4.py:L537）（95% CI 0.3019（run_d4.py:L538）–0.4632（run_d4.py:L539））低于目标中性基准，但该差值的符号依赖于目标暴露量基准的选择、可用规模代理本身对死站删失，且结构位置与站点健康在本横截面上互为候选解释，故只作为描述性差异报告，不作为"回避"或"传染"的证据。
