## 0. 判决

**这份数据的度分布不能称作“无标度 / 幂律”。** 主口径 `degree_u_671`，幂律 KS 最优 `x_min = 4`，`n_fit = 314`：

1. 幂律自身：KS = 0.1401，bootstrap p = 1.000 → 不可拒绝（`KEY['degree_u_671__powerlaw__ks_boot_p']`）。
2. 配对似然比 R(幂律 − 对数正态) = -16.67，正态近似 p = 0.0004 → **对数正态**在似然上更受支持。
3. 同一 x_min 上 KS 最小 = `powerlaw`（0.1401），AIC 最小 = `trunc_powerlaw`，BIC 最小 = `trunc_powerlaw`。
4. “尾指数”本身不稳定：x_min=1（全量 671）α = 1.5601；x_min=4（KS 最优）α = 1.9759，bootstrap 95% 区间 [1.9162, 2.0795]；x_min=19（无 6x² 约束）α = 2.7480；删 6 个导航枢纽的全部关联边后（x_min=1）α = 30.0000。四个都是合法口径下的“同一个分布的幂律指数”。

支持“**重尾**”（不指定分布族的较弱事实）的量彼此一致：Gini = 0.6158、CV = 1.6276、三阶中心矩 m3 = 7345.42、Top-1%（7 个节点）占无向度总量 11.74%、Top-10 个节点占 15.33%；全样本均值 7.438 而 10% 截尾均值 4.654（差 2.785）。

## 10. 局限

- 单次横截面、只有观察到的链接计数：任何分布形状都不携带机制解释；权重语义按 §1 写“观察到的链接次数”。
- 20 条 URL 的抓取上限截断出度/出强度，这是出度不进拟合的第二个理由（第一个见 §7 的删失）。
- 悬空引用节点（676 − 671 = 5）无属性，主口径排除，676 口径并列在 `fits.csv`。
- 参数化 bootstrap 假设“拟合分布为真”，且样本量只有 n_fit = 314，所以 `ks_boot_p` 是**候选族内**的相对可拒绝性，不是“模型为真”的概率。
- 度分布取值离散且不多（`degree_u_671` 唯一值 54 个），KS 在这种网格上偏保守：大 p 不能读成“确认幂律”。
- 抽样网格：`fits.csv` 的 `samp_trunc_mass` 给出该单元格 bootstrap 抽样时丢掉的尾概率；在 α→1 的单元格（尤其 `strength_u_671` 在 x_min 很小处）该值明显非零，对应 p 值要按“在截断版本上的检验”来读。
- 本单元只给排序与误差，不宣布“哪个替代模型为真”；截断幂律 / 对数正态 / 负二项在同一 x_min 上互有胜负（表 5）。
- 两处任务书与 CONVENTIONS 不一致、以及两处方法口径的必要放宽，见同目录 `DISSENT.md`。
