# E3_percolation · 渗流阈值 p_c

> 范围：定义 **p_c(level) = 首次使 GCC < level × GCC(0) 的删除比例 f = k / n0**，
> 两档 level = 50% 与 25%。基准图 = 674 主分量（n0=674，GCC0=674）。
> 本单元只逐点跟踪 GCC（不算效率），所以成本比 E1 低约三个数量级：**总墙钟 21.5 s**。
> `assert_anchors()` 31/31 PASS；静态确定性曲线与 E1 逐点完全一致（见 §5）。

## 0. 一句话结论

随机删点要跌破 **50%** 的 GCC 需要删掉 **40.8%** 的节点（这是「均值 GCC 曲线首次跌破」这个估计量；
200 次重复下「阈值的均值」是 **0.4095**，sd 0.0157 —— 两者差恰好 1 个网格步，见 §3），
而按介数或"无权无向 PageRank"排序只需 **11.3%**（k=76）——**比随机低 72.5%**；
跌破 **25%** 时随机需要 **63.6%**（sd 0.0180），介数/度/PR(无权无向) 只需 **14.5–17.5%**。
换句话说：这个网络对"按中心性挑点"极其脆弱，对随机故障则相当耐受（要删掉六成节点才掉到四分之一）。
**但 p_c 对排名口径的敏感度比节点集口径大一个数量级**（§4）。

## 1. 口径

| 项 | 取值 | 代码 |
|---|---|---|
| p_c 定义 | 最小的 k 使 GCC(k) < level·GCC(0)，报 f=k/n0；网格内未跌破则 NaN | `L119`–`L123` |
| 网格 | 每一个单点删除步，直到 **f=0.90**（k=607） | `L44`、`L192` |
| 节点集 | 主口径 674 主分量；敏感性 671 有属性 / 676 含悬空 | `L69`–`L82` |
| 排名基线（primary） | 二值无向度 / 二值无向介数 / 有向加权 PageRank（§5 主口径）/ 无权无向 PageRank（§5 对照）/ k-core | `L45`–`L52` |
| 排名基线（weighted） | `Gu` 强度 / 加权介数 / 加权无向 PageRank（k-core 无权重定义 → 不适用） | `L53`–`L59` |
| 随机 | **200 次独立重复 × 3 个节点集 = 600 条曲线**，`np.random.default_rng([20261113, rep])` | `L40`、`L207` |
| 导入 | 动态 p_c 读 E2 的 `e2_gcc_per_step.csv`（缺文件直接抛错，不静默跳过） | `L224`–`L228` |

**为什么网格要开到 0.90**：若只到 E1 的 f=0.60，随机策略在 25% 档会**右删失**——
第一轮实测 200 次里只有约 4.5% 的重复跌破 25%，报出来的"均值 0.594"其实是把 0.60 当成 0.59 的删失均值。
网格延到 0.90 后 `frac_reaches_threshold = 1.0`（600/600 都跨阈值），下面的 CI 才是真的 CI。

## 5. 交叉校验（可复现性）

- **确定性曲线**：本单元重算的 5 条静态 GCC 曲线与 E1 的 `e1_curve_gcc_per_step_deterministic.csv`
  **逐点完全一致，最大差 0 个节点**（`xcheck.per_strategy`，`L305`–`L313`）。
- **随机曲线**：E1 与 E3 用同一个 seed 公式与同一份 sorted 节点表，所以第 r 次重复是同一次抽样。
  把 E3 前 120 次重复单独取均值，与 E1 的 120 次均值最大差 **3.3e-05 个节点**（`L317`–`L322`）；
  用 E3 全部 200 次的均值去比，最大差 1.2433 个节点——**这个差来自"120 次 vs 200 次的抽样次数不同"，不是建图或口径漂移**。
  两条都写进 `E3_summary.json:cross_check_vs_E1`，避免后来的人把 1.24 当成不一致。

## 6. 局限

1. p_c 只依赖 GCC 规模，**不承载效率信息**；"谁先碎"不等于"谁损失更多效率"，效率要看 E1/E2。
2. 25% 档在本数据里对应"删掉六成节点"，已远离现实运维情景（真实观测失效是 162/674=24%）；正文引用时应说明这是极端情景。
3. `p_c` 是首次跌破阈值的**离散步**，GCC 曲线有平台，所以 p_c 的分辨率是 1/674；两策略相差 1–2 步时不应解读为排序。
4. 动态档只用了 E2 的 5 个策略；随机档没有"动态"对应物（随机本来无排名）。
5. PageRank 三列（有向加权/无权无向/无向加权）不可互换，见 E1 的 `DISSENT.md`。
