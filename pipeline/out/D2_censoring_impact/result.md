## (b) 同一个结论，两套口径（核心对照表，`d2_conclusion_contrast.csv`，`run_d2.py:L187`–`L228`）

均值与倍数：死站总度 1.8272 vs 健康站 9.4917 → **5.195×**（`L114`, `L117`）；死站入度 1.8272 vs 健康站入度 4.9417 → **2.705×**（`L113`, `L116`）；

## (c) 哪些统计量救不回来（`d2_recoverability.csv`，`run_d2.py:L231`–`L249`）

| 统计量 | 可否恢复 | 依据 |
|---|---|---|
| 死站的出度 | **不可恢复** | 观测值恒 0，真值域 [0, 95]（活站最大出度 95）；只能给区间/情景，不能给点估计 |
| 死站→死站的边 | **不可恢复** | 两端都不可观测；只能改写成可检验命题（D4 target-side 置换） |
| 死站→活站的边 | **不可恢复** | 起点页面未被抓取 |
| 死站的 hubness / 出强度 / 经过它的介数路径、有向 PageRank 的死站行向量 | **不可恢复** | 全部依赖出边；这些值是缺失值不是 0 |
| 页面级链接来源（谁在哪个页面链向谁）、时间维度 | **不可恢复** | urls.csv 仅 4 列；单次横截面 |
| 全网有向边集 / 出度分布 / 权重出强度 | **部分不可恢复** | 观测 2788 条是"少而真"的完整子集，非抽样；缺失量级见 (d) |
| 每个节点的入度 | **可恢复（下界性质）** | 观测入度 ≤ 真入度（起点为死站时该边仍缺失），统一称"观测入度" |
| 无向度（活站之间） | **可恢复** | 活站↔活站两方向都可观测 |
| 活站诱导子图的全部拓扑 | **可恢复** | 514 节点 / 2492 条有向边（`L162`, `L394`）——唯一口径自洽的图 |

## (d) 邻接矩阵缺失量级：**情景模拟**（不是数据）

做法（`run_d2.py:L252`–`L286`）：给 509 个活站按观测入度分层（`BANDS`，`L253`），取每层活站的出度分布，把"同入度层活站的出度均值/中位数/P75"指派给死站（层内匹配，`L267`–`L279`）；
另有放回抽样版本 `L289`–`L297`；目标端按观测入度∝偏好指派（`L300`–`L313`，200 次重复）。
**这是 counterfactual 情景，不是观测，也不是估计真值。**

**情景下的梯度会怎样**（`d2_counterfactual_exposure_gradient.csv`，`run_d2.py:L350`–`L370`）：把假想出度加给死站后，
`degree_u_cf` 下死站均值从 1.8272 升到 **5.3084**（健康站 9.4917 不变），十分位梯度从 **−58.80 pp（ρ=−0.9695, p=3.6e−06）塌到 +1.49 pp（ρ=0.3988, p=0.2536）**；
638 口径同样从 −57.81 pp 塌到 0.00 pp。入度口径不受影响（−32.33 / −32.81 pp）。
→ **情景模拟显示**：观测到的"总度梯度"里绝大部分是删失的同义反复；一旦按情景补齐出度，总度与健康的关联在数值上消失。这不是"真实梯度消失了"的证据，而是"总度口径下的梯度无法与删失分离"的证据。

## 结论（本单元三条）

1. 删失是结构性的：`edges_from_dead=0`、162/162 死站出度为 0、dead→dead=0（`L72`, `L96`, `L75`）；死站只有入边可观测（296 条 / 4276 权重）（`L76`, `L77`）。
2. 因此**同一结论在两套口径下差 1.921 倍**：无效 5.195× = 有效 2.705× × 1.921（`L116`–`L118`）；总度梯度 −58.80 pp 对比入度 −32.33 pp，差 26.47 pp 是口径伪影（`L141`）。凡"度/总度/无向度 × 健康"的表述必须挂在入度口径上。
3. 缺失量级：情景模拟给出 7.9%–18.4% 的边缺失区间（主口径 16.82%），而邻接矩阵 **23.96%** 的有序单元（死站行）**字面上完全未观测**（`L331`, `L340`）。这部分不能用任何校正填补成数据，只能用"情景"标出量级——本单元的全部补齐数字均标注 counterfactual。
