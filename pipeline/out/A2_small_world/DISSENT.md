# A2_small_world · DISSENT

三条都不是"改口径"的请求，而是**任务书给出的参照值与可复现算术不符**。本单元一律按
`CONVENTIONS.md` 与 `csa_common.py` 的口径出数，不改主口径；证据列在这里，供
`I1_number_consistency` / `I3_statistical_validity` 复核。

## D-1 任务书参照值 `ER 版 σ=23.26（C=0.013955、γ=22.83、λ=1.0018）` 三个数彼此不自洽

用同一个 `C_obs = 0.278777`（`gcc674`，已用 `csa_common` 锚点核对）做算术检查：

| 检查 | 参照值 | 由参照值自身推出 | 结论 |
|---|---|---|---|
| `γ = C_obs / C_er` | 22.83 = 0.2788/0.013955 | 右端实算 = **19.98** | 与 22.83 不符（差 14%） |
| 反解 `C_er = C_obs / γ` | — | **0.012212** | 与并列给出的 0.013955 不符 |
| `σ = γ / λ` | 23.26 | 22.83/1.0018 = **22.79** | 与 23.26 不符 |

本单元实测（`run_a2.py`，`N_INST=100`，`ER_gnp`，`p = k̄/(n-1) = 0.011010`）：

* `C_er = 0.010742`（`smallworld_metrics.csv`，`block=models, metric=C_lcc, model=ER_gnp`）。
  **理论校核**：ER 图的期望平均聚类系数恰好等于连接概率 `p`，即 `C_er ≈ p = 0.011010`；
  实测值与之相差 2.4%，落在 100 个实例的抽样误差内（`sd` 见 CSV）。
  参照值 0.013955 比 `p` 高 27%，比本单元实测高 30%，且高于任何 `p` 取值下的 ER 期望，
  因此**不可能**来自"同 n 同平均度的 ER"这一口径。
* `λ_er = 0.9382`（`metric=lambda, model=ER_gnp`），即观测图的平均路径**比同规模 ER 更长**，
  不是更短。参照值 `λ_er = 1.0018` 的成因见 D-2。

## D-2 参照值 `L_er = 3.2643` 用的是**调和平均**口径，与它并列的观测值 3.2702 是**算术平均**口径

`run_a2.py` 第 6b 节 `L_variants()` 把三种口径同时算出来（`block=F_L_convention`）：

| 口径 | 观测 `gcc674` | ER_gnp（100 实例均值） | 比值 |
|---|---|---|---|
| `L_lcc` 算术平均（Watts–Strogatz / `nx.average_shortest_path_length`，= 锚点 3.2702） | 3.2702 | 3.4859 | **0.938** |
| `L_harmonic_lcc` = 1/`global_efficiency`（`1/mean(1/d)`） | 3.0169 | 3.2623 | **0.925** |
| `L_reachable_all` 全图所有可达点对 | 3.2702 | 3.4859 | **0.938** |

参照值 3.2643 与 `L_harmonic_lcc = 3.2623`（n_inst=100，本单元；n_inst=6 时为 3.2675）吻合到 0.07%，
而与算术口径差 6.4%。但 `avg_pathlen_gcc = 3.2702` 是 `csa_common.ANCHORS` 里的**算术**口径
（`nx.average_shortest_path_length(GCC)`），并且它等于全图 `E_gcc = 0.3315` 的倒数 3.017 的**不同**值。
把 ER 用调和口径、把观测用算术口径相除，就会得到 `λ_er ≈ 1.00`——**跨口径相除**。

本单元的做法：分子分母固定用同一种口径（主口径 = 算术平均 `L_lcc`），并把另外两种口径并列写进
`smallworld_metrics.csv` 的 `F_L_convention` 段，不选边。任何一种一致口径下 `λ_er` 都 < 1，
所以"σ>1 由聚类一侧贡献、路径一侧并不比 ER 短"这个结论**不依赖口径选择**。

## D-3 任务书要求"只保留 360 个健康节点"，但 `GCC674` 内只有 **358** 个

`csa_common.node_sets()` 的 `gcc` 是 674 点分量，另一个 2 点分量是 `{bm.ustc.edu.cn, l.bm.ustc.edu.cn}`，
而这两个节点在 `add_health()` 里都是 `health_state='healthy'`（`ok_ratio_pct=100`）。所以
`len(b['fail']['healthy'] ∩ b['sets']['gcc']) = 358`，不是 360。

本单元两套都报，标签分开（`run_a2.py` 第 6 节 `subsets`，`block=E_health_subset`）：

* `gcc674_healthy358`：GCC 内诱导（与基线同分母，主口径）；
* `healthy360_in_gu676`：字面上的 360 个健康节点在 `G676` 上诱导（含分量外的 `{bm, l.bm}`）。

两者的最大分量都是同一个 338 点分量，所以 `L`、`diameter` 完全相同；只有 `C_all`（把孤立点也算进分母）
不同。这不改变任何结论，但**报数时必须写 358/338**，否则 `I1_number_consistency` 会对不上 360。

## D-4 已声明的方法学局限（不算异议，登记在此以免被当成"模型不达标"）

1. `C.degree_preserving_null` 的边交换不是均匀采样（Viger–Latapy 2005），函数 docstring 与
   `CONVENTIONS §4` 都已声明；本单元照抄该实现，未自行修改。
2. `nx.watts_strogatz_graph` 每侧只连 `k//2` 个邻居：**奇数 `k` 会让 ⟨k⟩=k-1**。
   观测 `k̄=7.4095` 取整是 7，落在不可实现的奇数上，所以 WS 只用偶数 `k∈{6,8}` 扫描，
   `⟨k⟩` 分别是 6.0 与 8.0，**两个都不能精确匹配 7.4095**。因此 WS 的 `σ` 只能当**夹逼参照**，
   不能当作"同平均度"的对照——写进 `smallworld_metrics.csv` 的 note 列。
3. D2b（仅重连保聚类）只动"两端都不在任何三角形里"的边，100 个实例与观测图平均重合
   80.6% 的边（`metric=overlap_obs, model=D2b_...`）→ 打散程度**低于**配置模型（14.1%）。
   它的 `L`、同配性变化因此只能读作"部分随机化后的保守下界"，不能读作"保聚类就一定保住短路径"。
