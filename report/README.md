## 一句话主线

> 这个网络**对随机故障稳健、对靶向攻击脆弱**；但它的很多“结构故事”是单次抓取的口径产物。  
> 一份好的分析，不是多跑一个指标，而是知道**哪些结论不能写**。

## 三条最稳的结论

1. 重尾，但不是幂律/无标度（A1）。
2. 随机 p_c(50%)=40.80%，介数 11.28%，度 11.42%（E3）。失效名单的剩余效率差在限定观测零出度的对照下接近零（E5 §8）。
3. 治理清单：下线 123 / 修复 121 / 保护 86 / 监控 5（G3，情景模拟）。

## 三条最容易被写错的

- ❌ “删死站让效率上升”——`E_full` 分母收缩；只看 `E_fixed`。
- ❌ “失效不聚集”——死站出度全 0，死—死相邻构造性不可识别。
- ❌ “25 个社区 / 社区=院系 / 5.2× / 149 个部分失效不加限定”。
